# 后台管理界面视觉参考

本目录保存后台管理界面后续 UI 优化参考图，来源为 imagegen 生成的高保真视觉稿。

## 推荐方向

- `admin-desktop-recommended-02.png`：推荐桌面端方向。整体更接近成熟 SaaS 后台，视觉重点较稳定，适合作为后续改造基准。
- `admin-mobile-recommended-01.png`：推荐手机端方向。延续现有顶部图标导航与页内 tabs 思路，信息密度和触控区域更适合移动端。

## 页面扩展参考

- `admin-login-reference-01.png`：登录页参考。使用更克制的品牌区、登录表单和系统状态提示，避免营销页式大图堆叠。
- `admin-dashboard-reference-01.png`：后台总览页参考。用于梳理 KPI、同步状态、近期活动和任务概览的层级关系。
- `admin-attempt-detail-reference-01.png`：答卷与评估详情页参考。用于候选人作答、评分摘要、AI 评估和侧边检查器的复合信息布局。
- `admin-status-logs-reference-01.png`：系统状态与日志页参考。用于服务健康度、运行指标、日志表格和阈值配置的管理界面。

## 备选参考

- `admin-desktop-calm-01.png`：较稳妥的桌面端方向，可用于对比布局与层级。

## 落地原则

- 主内容区优先使用连续工作面、细分割线和稳定表格网格。
- 卡片只用于 KPI、当前选中、评分摘要、风险提醒等需要第一眼看到的信息。
- 避免卡片套卡片、强装饰竖条、大面积渐变和多个同级视觉焦点。
- 桌面端保留左侧导航可折叠能力；移动端优先使用顶部图标主导航与页内分段 tabs。
